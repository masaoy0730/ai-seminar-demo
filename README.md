ヒヤリハットシナリオ（AL-2ラインの締結工程・日報からの気づき）：HTML動画版
https://masaoy0730.github.io/ai-seminar-demo/movie-nearmiss.html

- 内容：セイワ工機 生産技術部の立花 奈緒さん（マネージャー・AL-2ラインの立ち上げ責任者）が主人公。量産開始まであと1か月。毎朝目を通す前日の日報30件の中に、「リワークで入れ直すと、3本しか締めていないのに完了ランプが点いた気がする」という一行があった
- 見どころ：2段構成。まず日報30件から「確認したほうがよい記載」を5件挙げさせ、そのうちの1件をさらに調べる。不具合報告で空振りしたあと自分でヒヤリハット報告へ対象を広げ、6年間・2つの工場で9件の同じ構造の事象と、水平展開が止まっていた経緯を根拠つきで示す
- 構成：タイトル → 主人公 → 場面設定 → 記録の置き場所 → エージェント検索とは → 1回目の指示（日報30件） → 確認候補5件 → その一行 → 2回目の指示・処理の経過 → 回答 → 年表／なぜ届かなかったか → 根拠の原文と調査報告書 → まとめ
- 尺：4分19秒（オープニング・クロージング込み）。ナレーション：VOICEVOX:剣崎雌雄。画面内の文言はシナリオから作った再現

品質管理部シナリオ（設備メーカーの長い書類・Box＋社内の品質記録）：3分動画版
https://masaoy0730.github.io/ai-seminar-demo/movie-qc.html

- 内容：セイワ工機 品質管理部の高田 美咲さん（主任・AL-2ラインの工程内品質の担当）が主人公。新ラインの試作で、リーク検査のNGが朝の2時間だけ増え、再検査ではすべて合格。量産移行の判定まで10日
- 見どころ：Boxで共有している設備メーカーの取扱説明書（96ページ）・完成図書（210ページ）の後半にある記載を、エージェント検索が社内の品質記録と合わせて探し出し、原因候補と確認事項を根拠つきで示す
- 構成：タイトル → 主人公の紹介 → 場面設定 → Boxの画面（置き場所・検索） → Box標準検索の対象範囲（先頭 約1万バイト） → Box と Neuron の検索の違い → エージェント検索（指示 → 処理の経過 → 回答） → 逆の向き（見逃しのリスク） → エージェント検索でわかったこと（過検出と見逃し） → まとめ

法人融資シナリオ（メガバンクの行内調整・アクセス権限）：HTML動画版
https://masaoy0730.github.io/ai-seminar-demo/movie-loan.html

- 内容：あけぼの銀行 名古屋法人営業第二部の野口さんが、取引先（セイワ工機のサプライヤー）から設備資金8.2億円の相談を受け、稟議の前の行内調整を準備する

- 構成：タイトル → 主人公 → 場面設定 → 記録の置き場所 → キーワード検索 → エージェント検索とは → 指示 → 処理の経過 → 回答 → 根拠の原文 → アクセス権限による違い → 部署と上司のコメント → 事前相談資料 → まとめ

類似図面検索シナリオ（流用設計・設計部長が過去の判断を自分で確かめる）：HTML動画版
https://masaoy0730.github.io/ai-seminar-demo/movie-cad.html

- 内容：セイワ工機 プレス部品設計部の大久保 慎一さん（部長・設計歴20年）が主人公。設計審査の2日前、新しいブラケットの図番起票を見て「昔、材質を変えて別図番にした案件があった」と引っかかるが、図番もファイルの場所も思い出せない
- 見どころ：役員・管理職向け。覚えているのは「何があったか」「設計の根拠」で、度重なるシステム変更でファイルの場所は分からない。キーワード検索は覚えているキーワードのどれが本文にあるかを人が当てに行く必要があるが、エージェント検索は覚えていることをそのまま書けばよい（手がかりが多いほど強い＝経験の長い人ほど有利）。部下に調べてもらわず自分で確かめ、記憶どおりの経緯に加えて記憶になかった図面注記まで見つけ、審査用スライドの原案を作って部下に渡す
- 構成：タイトル → 主人公の紹介 → 場面設定 → 確かめる方法が3つ → キーワード検索 → エージェント検索とは → 指示の入力 → 処理の経過 → 回答 → 根拠の原文 → スライドの原案 → まとめ
- 尺：4分13秒（オープニング・クロージング込み）。ナレーション：VOICEVOX:剣崎雌雄。画面内の文言はシナリオから作った再現
