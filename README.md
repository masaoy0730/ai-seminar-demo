## parts ── デモHTMLの共通部品

HTML版デモ動画（`movie-*.html`）で使い回す画面モックを `parts/` にまとめています。
組み立て素材の `_build/` は `.gitignore` で除外しているため、**共有したい部品はこのフォルダに置きます**。

| ファイル | 中身 |
|---|---|
| [`parts/box-screen-mock.html`](https://masaoy0730.github.io/ai-seminar-demo/parts/box-screen-mock.html) | **Box の画面モック**。CSS・マークアップ・DRAW関数と、3つの状態（検索0件／1件ヒット／検索前のフォルダ一覧）の見本 |

ブラウザで開くと見本が表示され、同じページにコピー用のコードが並びます。
見本は実物と同じ HTML／CSS をその場で描いているので、**ページの見た目とコードは必ず一致します**。
使い方と守るルール（共有パネルを出さない、検索キーワードは `"` で囲って完全一致、0件の文言、右下の「Box画面はイメージです」など）は `parts/README.md` を参照してください。

Neuron 側の画面部品とあわせた作り方は、Claude のスキル `neuron-screen-mock` にまとめてあります。
