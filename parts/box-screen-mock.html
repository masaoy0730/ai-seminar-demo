Box 画面モック 部品集

研究開発部門向けデモ（movie-rd.html）で作った Box 画面のモックを、ほかの HTML 版デモでも同じ見た目で使えるようにまとめたものです。

実画面のキャプチャに合わせて作っています。右の共有パネルは出しません。

使い方

  1. 下の CSS を、デモ本体の <style>（または @@CSS@@ ブロック）に貼る。
  2. 見せたい状態の マークアップ を、シーンの中に貼る。.bxscr に left / top / width / height を指定して置く。
  3. DRAW 関数で typeTo() と grp() を呼び、検索語の打ち込みと結果の切り替えをする。

この部品は position:absolute で置く前提です。1920×1080 のステージなら left:140px; top:240px; width:1140px; height:600px が収まりの良い位置です（字幕帯にかからない）。

動かし方（DRAW 関数）


時間 l（シーン先頭からの秒数）で切り替えます。typeTo／grp は本編側のヘルパーです。


 s5:function(l){ rise(q("d1"),l,0.2,.5); rise(q("d2"),l,0.5,.6); rise(q("d3"),l,1.6,.6);
   var g1=false,g2=false,kw=""保持率"";
   if(l<5.2){ typeTo(q("d_q"),""保持率"",l,0.8,7); g1=(l>2.6); }
   else if(l<8.4){ typeTo(q("d_q"),""85℃・85%RH"",l,5.4,8); g1=(l>7.2); kw=""85℃・85%RH""; }
   else { typeTo(q("d_q"),""陽極酸化"",l,8.6,7); g2=(l>10.4); kw=""陽極酸化""; }
   q("d_kw").textContent=kw;
   grp(q("d_g1"),g1); grp(q("d_g2"),g2); },



注意：grp() は display と visibility の両方を切り替えること。ベースCSSの .grp{visibility:hidden} が残って、要素が見えなくなる不具合が出たことがあります。


function grp(el,on){ if(!el) return;
  el.style.display   = on ? "" : "none";
  el.style.visibility= on ? "visible" : "hidden"; }




守るルール（確認済み）


    

  • 右側の共有パネルは出さない（画面が狭くなり、検索結果が読めなくなるため）。
    • 

  • 右上の「今すぐ購入」は出さない。「トライアル」バッジも出さない（契約済みの顧客を想定するため）。
    • 

  • アバターの頭文字は主人公のイニシャルにする（研究開発部門デモでは仲井さんで KN）。
    • 

  • フォルダ名はデモシナリオのフォルダ名にする（demo_test のような作業用の名前を残さない）。
    • 

  • 検索語は " で囲って完全一致検索にする。ヒットしない理由を「表記ゆれでは？」と疑われないため。
    • 

  • 0件のときは「検索対象が見つかりませんでした。」の1行だけ。その下の案内文は出さない。
    • 

  • 画面の右下に「Box画面はイメージです」のバッジを必ず置く。
    • 

  • 実在の企業・製品・人名は出さない。ステージ左下に「※ 登場する企業・製品・文書・人名はすべて架空です」を出す。
    • 

  • Box を否定する見せ方にしない。「Boxに置いたまま、文書の奥まで探せる」という補完関係で見せる。
    •
