# parts ── デモHTMLの共通部品

HTML版デモ動画（`movie-*.html`）で使い回す画面モックを、ここにまとめています。
`_build/` は `.gitignore` で除外しているため、**共有したい部品はこのフォルダに置きます**。

| ファイル | 中身 |
|---|---|
| `box-screen-mock.html` | Box の画面モック。CSS・マークアップ・DRAW関数と、3つの状態（0件／1件ヒット／検索前のフォルダ一覧）の見本 |

## 使い方

1. ブラウザで `box-screen-mock.html` を開く（GitHub Pages でもそのまま開けます）。
2. ページ内の **CSS** をデモ本体の `<style>`（または `@@CSS@@` ブロック）に貼る。
3. 見せたい状態の **マークアップ** をシーンに貼り、`.bxscr` に `left / top / width / height` を指定する。
4. **DRAW 関数**で `typeTo()`（検索語の打ち込み）と `grp()`（結果の切り替え）を呼ぶ。

見本は実物と同じ HTML／CSS をその場で描いているので、**ページの見た目とコードは必ず一致します**。
部品を直すときは `box-screen-mock.html` の `<script type="text/plain" id="src-css">` と
`id="src-ab"` / `id="src-c"` を直してください。

## 守るルール

- 右の共有パネル、「今すぐ購入」、「トライアル」バッジは出さない。
- アバターの頭文字は主人公のイニシャルにする。
- フォルダ名はデモシナリオのフォルダ名にする。
- 検索語は `"` で囲って完全一致検索にする。
- 0件のときは「検索対象が見つかりませんでした。」の1行だけ（その下の案内文は出さない）。
- 右下に「Box画面はイメージです」のバッジを必ず置く。
- Box を否定しない。「Boxに置いたまま、文書の奥まで探せる」という補完関係で見せる。
